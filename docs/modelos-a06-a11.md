# A06–A11: modelos y evaluación

- **A06:** riesgo de inactividad con abstención para clientes fríos o sin historial y próxima compra basada en mediana de intervalos.
- **A07:** oportunidades de renovación, reactivación y venta cruzada con ID persistente y evidencia.
- **A08:** media móvil recursiva para horizontes configurables.
- **A09:** sensibilidad de costos USD con universo, TRM y diferencia COP visibles.
- **A10:** clasificación inicial de PQRS; textos vacíos o con múltiples intenciones pasan a revisión manual.
- **A11:** comparación de nulos contra referencia, denominador y estado de salud.

Estos componentes son reglas y líneas base reproducibles para el piloto. La activación empresarial requiere políticas, muestras autorizadas, revisión humana y un periodo de evaluación separado.
